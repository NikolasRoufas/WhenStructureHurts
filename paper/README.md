# Paper: "When Structure Hurts: Understanding Evidence Loss in Retrieval-Augmented Reasoning"

This is an ACL-format draft in anonymous review mode, written from the 2026-10-12 GPU campaign and revised (revision-1, 2026-10-13) with exploratory fixed-order controls, a retrieved-evidence replication and a prompt factor.

## Rebuild

The Mac used for development has little free disk, so builds run on the server.

```bash
# 1. analysis and figures (reads saved predictions only)
R=/data/roufas/wsh_campaign/research_outputs
cd /data/roufas/wsh_analysis
PYTHONPATH=src /data/roufas/when-structure-hurts/.venv/bin/python scripts/analysis/build.py \
  --runs $R/experiments/runs.json --out $R --paper paper \
  --figures-exp1 F_exp1 --figures-budget C_exp1 --figures-exp2 C_exp2 --forest-pilot C_exp1 --forest-confirm F_exp1
for L in F_exp1 C_exp1; do PYTHONPATH=src .../python scripts/analysis/decompose.py $R/experiments/runs.json $L $R/analysis/${L}_decomposition_exploratory.csv; done
PYTHONPATH=src .../python scripts/analysis/r4p_relations.py $R/experiments/runs.json F_exp1 $R/analysis/F_exp1_r4p_relations_exploratory.csv

# 2. tables
python3 scripts/analysis/tables.py $R/analysis $R/tables --paper-tables paper/tables

# 3. PDF (tectonic; its cache stays on /data)
cd paper && TECTONIC_CACHE_DIR=/data/roufas/tools/cache /data/roufas/tools/tectonic -X compile main.tex
```
